# 第三方许可

by: Long <mycjzb@gmail.com>

当前设计阶段**没有**第三方源代码、预编译库或下载的模型。

以后若某个可裁剪模块使用开源代码，必须在本文件记录：来源、版本、许可证、如何关闭该模块，以及它不链入核心。核心保持无强制第三方依赖。

自有网络第一版若启用，TLS 和所需摘要/HMAC/加解密使用仍受维护的 OpenSSL，经其公开高层 API 调用。当前没有源码、二进制或已核对的版本号，不把未核对的「最新版」写进文档。引入时补登记许可证、静态或动态、关闭开关和安全更新方式。HTTP 不由 OpenSSL 提供。不并行引入 mbedTLS 或 wolfSSL。

未记录许可的代码不能合并。
