## 2. 功能范围（本轮）

### 2.1 播放引擎（SHW = Media3）

- 默认引擎 Media3；`shw:` / `sys:` 源级切换；系统档为设备 `MediaPlayer`
- 协议：file / http(s) / HLS / DASH / rtmp(s) / rtsp / udp / rtp（详 SDK §9）
- 封装：TS、MP4/fMP4、FLV、MKV/WebM、AVI、MPEG-PS、裸 AAC/AC-3/…/FLAC/WAV 等
- 视频：**仅硬解**（MediaCodec）；无视频软解
- 直播掉窗：`BEHIND_LIVE_WINDOW` 自愈（seek+prepare，有限次）
- 缓冲 / 音频透传 / 播放 TLS 忽略证书 / HTTP 头：进 SHW prepare（见 SDK §8、§10）

### 2.2 多音轨 / 字幕 / 频谱

- `getTrackInfo` / `selectTrack` / `deselectTrack` / `getSelectedTrack`
- 内嵌 + 外挂文字字幕；DVB/PGS 等位图（`TimedText` 位图 + 可选 `SubtitleBitmapOverlay`）
- 字幕默认关闭，需选轨；外挂不加 DEFAULT
- `getAudioBars`：Tee PCM → 5 段 0–255；**透传无 PCM 时恒 0，属正常**
- 纯音频 Progressive 可播

### 2.3 常用音频软解（FfAdec）

系统 MediaCodec 没有时，`EXTENSION_RENDERER_MODE_ON` 回落 FFmpeg 软解 → PCM：

| 支持 | 不支持 |
| --- | --- |
| AAC / LATM、MP2、MP3、AC-3、E-AC-3、DTS、DRA、G.711 | **WMA**（无 ASF demux，仅软解无意义） |
| **Opus、FLAC、PCM、Vorbis、ALAC**（本轮扩容） | 视频软解 |

须使用带本次 `ADEC_LIST`（含 opus/flac/vorbis/alac）编出的 so；**只换 dex 不够**。

### 2.4 JS 规则脚本（QuickJS）

对齐公开 [JS 解析规则](https://www.aliiptv.com/js-rules)；细节见 SDK §12。

| 能力 | 说明 |
| --- | --- |
| 触发 | URL 正文为 `function main` / gzip / **MSJS** 密文；或 `asset:///js/….js` |
| API | 仅 `ms.*`（无 ku9/cjs） |
| 返回 | **A** 可播 url；**B** m3u8/body 内存起播 |
| 分片 | `stream` + 固定名 `stream_call(url, args)` → 字节喂播放器 |
| 样例 | 央视频 YSP、广西 gxtv、河南/凤凰/山东/河北/芒果等，见 `samples/js/README.md` |

老盒 API18：so 内补 `rand` 等符号，避免 QuickJS dlopen 失败。

## 3. 明确不做 / 已知限制

- 不做 WMA/ASF；不做纯 `.ogg`（无 OggExtractor）
- Vorbis：多段 csd 当前为直拼，**部分片源可能软解失败**（未做 Xiph 封装）
- HLS SAMPLE-AES / DRM 不支持
- 系统档：选轨/缓冲/透传/TLS/外挂字幕能力弱或空
- msm3 演示频道列表与内置 JS **非**客户必交业务内容
- iOS / Windows 不在本交付

## 4. 用途（反推）

| 谁用 | 何时 | 不做会怎样 |
| --- | --- | --- |
| 集成方 App | 直播/点播起播、切音轨、挂字幕、弱盒无硬解音频 | 无声/起播失败；多音轨 API 空转 |
| 运营/内容 | 规则脚本解析台源（YSP/省台等） | 只能写死 URL，无法热更解析 |
| 机顶盒 | 缺 Opus/FLAC 等 OMX 时 | 有画无声或直接 Error |

## 5. 验收建议（客户自测）

不替代客户签字；建议至少：

1. **直播 HLS**：长时间播放，掉窗可恢复，不长期定格  
2. **多音轨**：菜单/红键切轨有声切换  
3. **字幕**：选 DVB/外挂 SRT，文字或位图可见；取消选轨清屏  
4. **软解**：无对应硬解设备上 WebM Opus / FLAC / m4a ALAC 有声；原有 AC-3/E-AC-3 回归不破  
5. **JS**：`asset` 或 http 脚本 → A/B 起播；带 `stream` 的台（如广西）出画；YSP 密文清单不误解封装  
6. **正式包**：release 签名与 so 内指纹一致，受保护入口可用  

频谱：非透传有 PCM 时 bars 非全 0；开透传为 0 不判失败。

## 7. 客户编包提示

```bash
# QuickJS 源码（若缺）
bash scripts/fetch_quickjs.sh

# slimff + ADEC so（须含当前 ADEC_LIST）后按工程习惯打入 jniLibs
# 压壳正式包务必先改 apk_sign 指纹再 PACK_SO=1
```

具体命令以客户约定的 `build_msm3` / `scripts/build.sh` 为准；**交付方不代跑客户环境编译**时，以已提供的 so + 源码树为准。
